# Simple Version – Dokumentation Benutzer

Dokumentation für **Benutzer:innen**. Du arbeitest mit den Archiven in den dir
**zugewiesenen Ordnern** – ohne Verwaltungs- und Löschrechte.

---

## 1. Überblick: Was du kannst

| Aktion | In deinen zugewiesenen Ordnern |
|---|---|
| Ordner sehen | ✓ (nur zugeteilte + Pfad dorthin) |
| Dateien hochladen / neue Version anlegen | ✓ |
| Kommentare schreiben | ✓ |
| Bearbeitungsstatus setzen (In Bearbeitung / Freigeben) | ✓ |
| Dateien herunterladen | ✓ |
| Verlauf & Kommentare ansehen | ✓ |
| Ordner anlegen / umbenennen / löschen | ✗ |
| Dateien oder Versionen löschen | ✗ |
| Benutzer / Rechte verwalten | ✗ |

Alle Einschränkungen gelten **serverseitig** – nicht nur das Ausblenden von
Schaltflächen.

---

## 2. Anmelden

1. Anwendung im Browser öffnen: `http://<server-ip>:8001`
2. Benutzername und Passwort eingeben, **Anmelden** klicken.
3. Oben rechts siehst du deinen Namen und dein Rollen-Badge **„Benutzer"**.
4. **Abmelden:** Button „Abmelden" oben rechts.

> **Passwort ändern:** Oben rechts auf **„Passwort ändern"** klicken.
> Aktuelles Passwort und zweimal das neue Passwort eingeben → **Speichern**.
> Das geht für jede Rolle (auch Benutzer) **jederzeit selbst** – du musst dich
> dafür nicht an Supervisor oder Administrator wenden.
>
> Passwort vergessen? Dann wende dich bitte an deinen Supervisor oder
> Administrator – er kann das Passwort zurücksetzen.

---

## 3. Deine Ordner

In der linken Leiste siehst du **nur die Ordner, die dir zugeteilt wurden**.

- Klicke einen Ordner an, um seinen Inhalt zu sehen.
- Ordner, die nur dem **Pfad** zu deinem zugeteilten Unterordner dienen,
  werden ohne Aktionen angezeigt: Du kannst sie **nicht öffnen** (kein Inhalt,
  kein Upload) – sie führen lediglich (wie eine Ordner-Navigation) zu deinem
  Bereich.

*Beispiel:* Dir wurde „SPS" (unter „Testbereich 1") zugeteilt. Du siehst
„Testbereich 1" nur als Pfad; öffnen kannst du „SPS" und seine Unterordner.

---

## 4. Datei hochladen (neue Version)

1. Den Zielordner anklicken.
2. **„Datei hochladen"** / den Upload-Bereich wählen.
3. Datei auswählen.
4. In das Pflichtfeld **„Kommentar"** einen beschreibenden Text eingeben
   (z. B. „Programmstand 2026-09-09, Fehler GET-17 behoben").
5. **„Hochladen"** klicken.

**Wichtig:**
- Ein Kommentar ist **Pflicht** – der Upload wird sonst abgelehnt.
- Jeder Upload des gleichen Namens erzeugt die **nächste Version**
  (V1, V2, V3 …) mit Zeitstempel und Verfasser. Genau deshalb lohnt der
  Kommentar: Er erzählt der nächsten Person, *was* sich geändert hat.
- Auf **Archivebene** anzeigen: In der Karte erscheint die aktuelle Version,
  in den Details alle.

---

## 5. Bearbeitungsstatus

Der Status einer Datei zeigt den Zustand:

- **In Bearbeitung** – es wird gerade an der Datei gearbeitet
  („✎ Bearbeiten" in der Archiv-Karte, **Kommentar Pflicht**).
- **Freigegeben** / „✓ Freigeben" – die Datei gilt als fertig/abgenommen
  (Kommentar optional).

Statuswechsel sind auch nachträglich jederzeit möglich und erscheinen im Verlauf.

---

## 6. Kommentare und Verlauf ansehen

Klicke auf **„Details"** (💬) in der Archiv-Karte. Du siehst:

- **alle Versionen** mit Dateiname, Versionsnummer, Zeitstempel, **Verfasser**
  und direktem **Download**-Link,
- **alle Einträge** des Verlaufs (Upload, Bearbeiten, Freigeben, Kommentare) –
  **neuester zuerst**,
- wer was zu welchem Zeitpunkt geschrieben hat (z. B. „Muster, Karl –
  am 09.09.2026, 10:12").

So bleibt lückenlos nachvollziehbar, wann wer welche Datei in welchem Stand
hinterlegt hat.

---

## 7. Datei herunterladen

- **⬇-Symbol** in der Archiv-Karte: lädt die **aktuellste** Version herunter.
- Im **Details**-Dialog: jede Version einzeln per Download-Link.

---

## 8. Was du niemals darfst (und warum)

- **Nichts löschen** – nicht Dateien, nicht Versionen, nicht Ordner.
- **Keine Ordnerstruktur ändern** – anlegen, umbenennen, verschieben.
- **Keine Rechte verwalten** – eigene Ordner-Zuteilung bestimmt
  ausschließlich dein/e Supervisor oder Admin.

Das schützt die Historie: In einem Prüfungs-/Audit-Umfeld muss jeder Eintrag
erhalten bleiben. Wenn du etwas falsch abgelegt hast, sage deinem Supervisor
Bescheid – er kann es wieder gerade ziehen.

---

## 9. Kurzanleitung (Cheat-Sheet)

| Ich möchte … | So geht’s |
|---|---|
| Neuen Stand ablegen | Ordner öffnen → Upload → Kommentar → Hochladen (→ neue Version) |
| Verdeutlichen, dass ich dran arbeite | Karte → **✎ Bearbeiten** → Kommentar |
| Fertig melden | Karte → **✓ Freigeben** |
| Alten Stand herunterladen | Karte → **Details** → Version wählen → ⬇ |
| Verlauf sehen | Karte → **Details** (neuester Eintrag oben) |
| Passwort ändern | oben rechts → **„Passwort ändern"** (selbst möglich) |
| Etwas löschen | nicht möglich – bitte Supervisor kontaktieren |
